FAANG 7-Day Revision Sprint

A highly focused 7-day loop designed to maintain muscle memory across all 15 core Google L4 topics.

Day 1

Arrays, Strings & Two Pointers

  • Array/Matrix: Prefix Sum, Cyclic Sort, In-place Tracking
  • String: Palindromes, Anagrams (Hashing), Window Formats
  • Two Pointers: Converging (2Sum/3Sum), Fast, & Slow (Cycles)
Recall Drill: Write the Cycle Detection (Tortoise and Hare) template natively in 2 mins.
Day 2

Sliding Window, Linked Lists & Stacks

  • Sliding Window: Fixed Size (Max Params), Variable (Longest Substring)
  • Linked List: In-place Reversal, Intersection, Merging K Lists
  • Stack: Monotonic Decreasing (Next Greater Element), Parsing
Recall Drill: Write the full Variable Sliding Window template ("expand right, shrink left conditionally").
Day 3

Binary Search, Heaps & Greedy

  • Binary Search: Value vs. Index, Min/Max Limits, Rotated Arrays
  • Heap: Top K Elements, 2-Heap Combinations (Median)
  • Greedy: Interval Merging, Jump Game Variants
Crucible Drill: Write Binary Search on Answer logic (e.g., Koko Eating Bananas limit checks).
Day 4

Trees & Systems Design Patterns

  • Tree Traversal: Level Order (BFS), In/Pre/Post (DFS), LCA
  • Design: Tries (Prefix Trees), LRU Cache, Custom Data structures
Recall Drill: Build out an LRU Cache backbone (Doubly Linked + HashMap) within 4 mins.
Day 5

Graphs & Bit Manipulation

  • Graph: DFS/BFS Counting, Topo Sort (Kahn's), Union-Find, Dijkstra
  • Bit Manipulation: XOR properties, Hamming Weights
Heavy Drill: Write a fully optimized Union-Find class (Path Compression + Union by Rank).
Day 6

Dynamic Programming (Deep Dive)

  • 1D DP: Fibonacci, Subsequence Sums (House Robber)
  • 2D DP: Grid Paths, LCS, 0/1 Knapsack variations
  • State Combos: Stock Problems, Edit Distance
Crucible Drill: Understand the grid DP framework. Write Longest Common Subsequence logic flawlessly.
Day 7

Backtracking & Simulation

  • Backtracking: Subsets, Permutations, Combination Sum, Word Search
  • Matrix Simulation: Spiral Paths, Game of Life checks
Crucible Drill: Write the Subset generation algorithm recursively pushing and popping paths cleanly.
